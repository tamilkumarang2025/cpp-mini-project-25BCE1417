# Student Performance System

A simple C++ mini project to manage student marks (CAT1, CAT2, FAT).

## Features

* Add, update, delete students
* Calculate total, average, grade
* Store data using file handling
* Generate basic reports

## Tech Used

C++, STL, File Handling, HTML, CSS, JavaScript

## Run

Compile using:
em++ main.cpp -o index.html
